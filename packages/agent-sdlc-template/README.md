# Agent SDLC Template

This package contains the abstracted template of the Autonomous Software Factory configurations used at RiddimSoftware.

## What's included?
- `template/agent-config`: The repository structure for `CLAUDE.md`, context files, and the architecture governance framework.
- `template/skills`: The prompt templates for the Backlog Team, Architecture Team, and more.

## Usage
Copy the contents of `template/agent-config` and `template/skills` into your own repositories to bootstrap an autonomous SDLC.
