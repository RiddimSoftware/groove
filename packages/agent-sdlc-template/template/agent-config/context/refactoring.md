# Refactoring

**Core Rule:** Refactoring is the process of changing a software system in such a way that it does not alter the external behavior of the code yet improves its internal structure.

When a task involves refactoring existing code to improve its design, remove technical debt, or prepare it for a new feature, you must strictly adhere to the principles of safe, behavioral-preserving transformations.
