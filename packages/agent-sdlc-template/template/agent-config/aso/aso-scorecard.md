# ASO Scorecard

A rubric for evaluating the App Store Optimization health of a single product (one app on one store, or one app aggregated across stores). Each criterion is scored 0–10. Use this rubric on a recurring cadence per product, and treat the score as a planning input — not a grade. Findings translate into Linear issues, not edits made directly to App Store Connect or Google Play Console.

## I. Visibility

| Criterion | 0–10 | Notes |
| :--- | :--- | :--- |
| **Keyword Targeting** | | Are Title, Subtitle/Short Description, and keyword field deliberate? Top priority keywords placed in highest-weighted fields? |
| **Keyword Coverage** | | Backlog refreshed in the last quarter? Long-tail and competitor terms researched, not just brand and obvious generics? |
| **Search Rank Position** | | Top-10 for primary keywords? Tracking shows trend, not a single snapshot? |
| **Browse & Explore** | | Category placement deliberate? App appears in "Similar Apps" / "You Might Also Like" for relevant competitors? |
| **Feature Visibility** | | Active relationship with store editorial? Pitch sent within the last 6 months when warranted? |
| **Paid–Organic Synergy** | | Apple Search Ads (and Google App Campaigns) structured to lift organic ranks? Brand keyword defended? Cannibalization measured? |

**Visibility subtotal:** / 60

## II. Conversion

| Criterion | 0–10 | Notes |
| :--- | :--- | :--- |
| **Icon** | | Recognizable at small sizes? Matches brand? Tested in the last 12 months? |
| **Screenshots** | | Hierarchy clear (most important feature first)? Captions readable on small displays? Visual Word Recognition reinforces target keywords? |
| **Video / App Preview** | | Value prop visible in the first 3 seconds? Captions for sound-off viewing? Poster frame chosen deliberately? |
| **Copy & Metadata** | | Title front-loaded with the value prop, not just keywords? Subtitle / Short Description complements, doesn't repeat title? |
| **What's New / Promotional Text** | | Updated within the last 30 days? Reflects active development and recent wins? |
| **A/B Testing Cadence** | | At least one test run in the last quarter? Wins shipped and re-baselined? Causal analysis used when native A/B isn't available? |
| **CRO vs. Benchmark** | | Search Conversion Rate (App Store) and Store Listing CR (Google Play) compared to category benchmarks, not raw numbers? |

**Conversion subtotal:** / 70

## III. Localization

| Criterion | 0–10 | Notes |
| :--- | :--- | :--- |
| **Locale Coverage** | | Top revenue/install markets covered beyond English? FIGS/PR/CJK considered? |
| **Translation Quality** | | Native-speaker review for visible metadata (title, subtitle, short description)? Not relying on auto-translate for revenue-critical markets? |
| **Keyword Research per Locale** | | Local keyword research, not a literal translation of English keywords? |
| **Culturalization of Creatives** | | Screenshots culturalized for major markets (local models, currency, units, fonts)? |
| **Custom Pages** | | Google Play Custom Store Listings / App Store Custom Product Pages used for country- or audience-specific traffic? |

**Localization subtotal:** / 50

## IV. Ratings & Reviews

| Criterion | 0–10 | Notes |
| :--- | :--- | :--- |
| **Star Average** | | At or above 4.5 stars on both stores? Below 4.0 is a structural disadvantage. |
| **Volume & Velocity** | | Enough recent ratings to keep the average current? Reviews coming in steadily, not just in bursts after launches? |
| **Prompt Trigger Quality** | | Triggered at user "aha" moments, not on cold start? Server-side configurable? Respects per-store cooldown limits? |
| **Reply Discipline** | | Featured/upvoted reviews answered? Replies personal, not templated? Negative reviews acknowledged and routed to support fixes? |
| **Sentiment Mining** | | Reviews mined for product feedback feeding back into roadmap and CRO research? |

**Ratings subtotal:** / 50

## V. Tooling & Insights

| Criterion | 0–10 | Notes |
| :--- | :--- | :--- |
| **ASO Tool** | | Primary ASO tool configured, tracking the right keywords, with someone responsible for reviewing the data? |
| **MMP** | | Mobile Measurement Partner integrated; organic vs. paid attribution trustworthy? |
| **Dashboards** | | Unified dashboard (e.g., Looker Studio) replacing the App Store Connect ↔ Play Console ↔ MMP context switch? |
| **Cannibalization Monitoring** | | Brand keyword spend vs. organic decay measured? Cost-Per-Protected-Install modeled? |
| **Seasonality & Macro Watch** | | Calendar of events relevant to the app's category and target locales? Seasonal CRO opportunities triaged, not ignored or chased reflexively? |

**Tooling subtotal:** / 50

---

**Total Score:** / 280

### Score Interpretation

- **0–139 (≤50%):** Foundational gaps. Stop optimizing; start with keyword research, locale strategy, and rating prompt setup.
- **140–195 (50–70%):** Operating but leaking value. Prioritize the lowest-scoring vertical and a clear A/B test cadence.
- **196–251 (70–90%):** Healthy. Focus on incremental wins, localization depth, and ASA–organic synergy.
- **252–280 (≥90%):** Best-in-class. Hold the line via cadence; defend against algorithm changes and competitor moves.
