# Architecture Scorecard

A rubric for evaluating the architectural health of a project or PR.

| Criterion | 0-10 | Notes |
| :--- | :--- | :--- |
| **Dependency Direction** | | Dependencies point inward? |
| **Separation of Policy/Detail** | | Business rules isolated? |
| **Testability** | | Isolated unit tests? |
| **Boundary Clarity** | | Explicit ports and adapters? |
| **Framework Independence** | | Core logic framework-free? |
| **Data Model Isolation** | | Domain models free of persistence details? |
| **Use Case Clarity** | | Clear, named use cases? |
| **Coupling/Cohesion** | | High cohesion, low coupling? |

**Total Score:** / 80
